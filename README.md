# Waitless Backend

Backend API for the Waitless application built with Spring Boot.

## Tech Stack
- Java + Spring Boot
- REST API
- PostgreSQL (database)

## Getting Started

### Prerequisites
- Java 17+
- Maven

### Run Locally
```bash
./mvnw spring-boot:run
```

## API
Base URL: `http://localhost:8080`

## Deployment
Deployed on Render.
